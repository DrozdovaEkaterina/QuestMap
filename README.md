# QuestMap

Интерактивная карта-квест: доска из Miro, перенесённая в один HTML-файл. Все 279 элементов стоят на своих местах (картинки, стикеры, тексты, связь между деревьями). Элементы можно перетаскивать, чтобы найти спрятанные за картой карточки и частички пергамента.

Несколько людей могут двигать элементы одновременно: перемещения видны всем сразу и сохраняются в Firebase Realtime Database, пока кто-то не нажмёт «Вернуться в начало».

## Состав

- `index.html`: вся карта в одном файле, картинки встроены (WebP, около 6 МБ).
- `database.rules.json`: правила безопасности базы данных Firebase.

## Настройка за 3 шага

1. **Правила базы.** Firebase Console → Realtime Database → вкладка **Rules** → вставьте содержимое `database.rules.json` → **Publish**. Без этого база закрыта, и страница покажет «Нет связи с базой данных».
2. **Загрузка на GitHub.** В репозитории: **Add file → Upload files** → перетащите `index.html`, `database.rules.json`, `README.md` → **Commit changes**.
3. **Публикация сайта.** **Settings → Pages → Deploy from a branch** → ветка `main`, папка `/ (root)`. Через минуту-две сайт откроется по адресу `https://<ваш-логин>.github.io/QuestMap/`.

Адрес базы записан в начале скрипта в `index.html` (константа `DB_URL`). Если создадите другую базу, замените его там.

## Управление

- Перетаскивание элемента: мышь или палец. Карточка и её надпись двигаются вместе, как в группе Miro.
- Масштаб: колесо мыши или два пальца. Сдвиг карты: перетаскивание пустого места. «Вся карта»: общий вид.
- «Вернуться в начало»: возвращает все элементы на исходные места у всех участников после ввода пароля. Пароль в коде не хранится, в файле лежит только его хеш (PBKDF2, SHA-256). Пароль принимается на русской и английской раскладке.

## Как это устроено

- Положения хранятся в `layout/p` (ключ группы → смещение `x`, `y`), присутствие участников в `presence`.
- Страница слушает базу потоковым соединением (Server-Sent Events) и пишет через REST, SDK Firebase не нужен.
- Пока база недоступна, элементы всё равно двигаются, но только у вас; в статусе будет написано, что связи нет.

## Безопасность

- Доступ к карте открыт всем, у кого есть ссылка: войти по аккаунтам на статическом сайте нельзя.
- Правила базы ограничивают формат данных (только ключи групп и числа в разумных пределах), но не запрещают запись посторонним.
- Пароль на сброс проверяется в браузере, поэтому он защищает от случайного нажатия, а не от технически подкованного человека. Для жёсткой защиты сброс нужно переносить на сервер (например, в облачную функцию Firebase).
